## To run this project: 

- Download and Install Ollama from https://ollama.ai
- Verify installation with command ```which ollama```
- Run the command ```ollama pull deepseek-r1:14b*```
- Create a venv with command ```python3 -m venv venv```
- Activate venv with command ```source venv/bin/activate```
- Install requirements with ```pip3 install -r requirements.txt```
- In a separate terminal start Ollama with command ```ollama serve```
- Run the file ```python3 v2.py```

# ``` * the model to be downloaded is subject to change so make sure you check before downloading```
